# Code of Conduct

This project follows the [Contributor Covenant v2.1][cc].

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

In short: be respectful, assume good faith, and keep technical disagreement technical.
Harassment, personal attacks, and demeaning comments are not welcome.

Report problems to the repository owner via a [private security advisory][advisories] or a
direct message on GitHub. Reports are handled confidentially.

[advisories]: https://github.com/iamvazghen/jev-governor/security/advisories/new

Maintainers may remove comments, close issues, or block accounts that breach this.
